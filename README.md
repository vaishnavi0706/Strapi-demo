# Strapi Demo – Vaishnavi

This project demonstrates how to clone the Strapi repository, run Strapi locally, explore the project structure, start the Admin Panel, create a sample content type, and push the setup to GitHub with a Pull Request.

---
## 📌 Task Summary

The task was to:

- Clone the Strapi repository
- Run Strapi locally
- Explore the folder structure
- Start the Admin Panel
- Create a sample content type
- Push the setup to GitHub
- Create a Pull Request
- Record a Loom video

## ⚙️ Prerequisites

- Node.js (v18+)
- Yarn
- Git
- WSL / Linux / macOS / Windows

  ## 🚀 Steps Performed

### 1. Clone the Strapi Repository

```bash
git clone https://github.com/strapi/strapi.git
cd strapi

### 2. Install Dependencies
yarn install

### 3. Run Strapi Locally
cd examples/getstarted
yarn develop

### 4. Strapi runs at:
http://localhost:1337

Access Admin Panel: http://localhost:1337/admin

### 5 . Create Sample content Type and test API
http://localhost:1337/api/posts
